Método

El mismo método, en distintas organizaciones.

Las herramientas cambian de un proyecto a otro; lo que se repite es la forma de trabajar.

  1. Integrar fuentes dispersasExtraer y unir información de sistemas y archivos distintos.
  2. Validar y conciliar cifrasControles que permiten defender un número ante quien lo pregunte.
  3. Modelar y definir métricasUna definición única para cada indicador.
  4. Automatizar lo repetitivoQue el proceso corra solo y deje trazabilidad.
  5. Diseñar para el usuario que decideLa misma información, con la lectura de cada rol.
  6. Gobernar la informaciónEstándares, definiciones y distribución controlada.
